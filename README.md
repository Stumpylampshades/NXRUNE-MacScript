# NXRUNE-MacScript
Additional shell script to allow for easier patching for players on MacOS.
Shell script adapted from Linux script in Game Jolt download.

# How to use (simple version)
Step 1: Run batch_install.sh

Step 2: Enter DELTARUNE directory (path to .app is fine)

Step 3: Enjoy

# How to use (detailed version):
Step 1: Extract downloaded code

Step 2: Right click `batch_install.sh` in finder while holding option and select `Copy "batch_install.sh" as Pathname`

Step 3: Open Terminal and run `bash` followed by pasting the path you copied (i.e. `bash /Users/you/Downloads/NXRUNE-MacScript/batch_install.sh`)

Step 4: Enter DELTARUNE path (path can be obtained the same way you got the path to the .sh script), right click + option.

Step 5: Enjoy!
